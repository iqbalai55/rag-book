# Book-QA API Documentation

## Overview

Base URL: `http://localhost:8001`

**Authentication**: All endpoints require `x-api-key` header.

---

## Endpoints

### 1. Chat Stream - `POST /book-qa/stream`

**Description**: Interactive chat with RAG agent (streaming SSE response).

**Rate Limit**: 10 requests/minute

**Request Body**:
```json
{
  "user_id": "user-123",
  "session_id": "session-abc",
  "book_id": "book-xyz",
  "messages": [
    {"role": "user", "content": "What is photosynthesis?"}
  ]
}
```

**Response**: Server-Sent Events (SSE) stream with chunks:
```
data: {"id": "chatcmpl", "type": "internal", "content": "Let me think...", "metadata": {"tool_calls": [...]}}\n\n
data: {"id": "chatcmpl", "type": "tool", "content": "...", "metadata": {"tool_name": "..."}}\n\n
data: {"id": "chatcmpl", "type": "final", "content": "Photosynthesis is...", "metadata": {}}\n\n
data: [DONE]\n\n
```

**Chunk Types**:
| Type | Description |
|------|-------------|
| `final` | Final AI response |
| `tool` | Tool execution result |
| `multiple_choice_question` | MCQ generated by `generate_mcq` tool |
| `essay_question` | Essay questions from `generate_essay_questions` tool |
| `internal` | Internal reasoning (before tool calls) |
| `error` | Error occurred |

**Errors**:
- `402` - Insufficient credits
- `422` - Validation error
- `429` - Rate limit exceeded

### 2. Ingest PDF - `POST /book-qa/ingest`

**Description**: Upload and ingest a PDF book into the vector database.

**Rate Limit**: 3 requests/minute

**Request**: `multipart/form-data`

| Field | Type | Description |
|-------|------|-------------|
| `file` | file | PDF file (required) |
| `book_id` | string | Book identifier (required) |

**Response**:
```json
{
  "status": "success",
  "collection": "lms_content",
  "book_id": "book-xyz",
  "storage_url": "https://storage.supabase.co/bucket/path/file.pdf",
  "message": "my-book.pdf ingested and stored"
}
```

**Errors**:
- `500` - Processing error

### 3. Generate Mindmap - `POST /book-qa/mindmap`

**Description**: Generate a mind map from book content.

**Rate Limit**: 5 requests/minute

**Query Parameters**:
| Parameter | Type | Description |
|-----------|------|-------------|
| `user_id` | string | User identifier (required) |
| `book_id` | string | Book identifier (required) |
| `user_prompt` | string | Optional instructions for mindmap style |

**Response**:
```json
{
  "book_id": "book-xyz",
  "title": "Photosynthesis Overview",
  "mermaid": "mindmap\n  root((Photosynthesis))\n    Light Reactions\n      Photosystem II\n      Photosystem I\n    Dark Reactions\n      Calvin Cycle",
  "sources": ["biology-book.pdf (hal 45-67)"]
}
```

**Errors**:
- `402` - Insufficient credits (cost: 0.02)
- `404` - No content found for this course

## Streaming Chunk Format

All streaming endpoints use Server-Sent Events (SSE) with JSON chunks:

```javascript
// Parse SSE stream
const eventSource = new EventSource('/book-qa/stream', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', 'x-api-key': 'your-key' },
  body: JSON.stringify(payload)
});

eventSource.onmessage = (event) => {
  if (event.data === '[DONE]') {
    eventSource.close();
    return;
  }
  const chunk = JSON.parse(event.data);
  console.log(chunk.type, chunk.content);
};
```
